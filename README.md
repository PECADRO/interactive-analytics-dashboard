# Interactive Analytics Dashboard

Interactive Analytics Dashboard is a lightweight business intelligence interface for tracking performance data in one place. It gives teams a quick view of revenue, customers, traffic, growth, and operational trends without needing a complex analytics platform.

## What This App Does

This dashboard is designed to help businesses understand what is happening across their data at a glance. It combines summary KPIs, visual reports, and a transaction table so teams can monitor sales performance, identify patterns, and react quickly when numbers change.

The app is especially useful for:

- tracking revenue movement over time
- reviewing where traffic and customers are coming from
- comparing business metrics across categories and months
- checking recent transactions and activity trends
- switching between light and dark themes for comfortable day-to-day use

## Why It Matters

The main goal of this project is speed and clarity. Instead of digging through raw spreadsheets or multiple tools, users can open one dashboard and immediately see the state of the business. The layout is simple to read, responsive on different screen sizes, and built to support quick decision-making.

## Key Capabilities

- revenue, category, traffic, user growth, radar, and comparison charts
- KPI cards for revenue, users, orders, and conversion rate
- searchable and paginated transactions table
- live-style refresh that regenerates dashboard data
- revenue period control and user growth filters
- theme switching for a cleaner viewing experience
- export support for sharing chart visuals

## Built For

This project is a good fit for small businesses, operations teams, sales teams, and demo environments where people need a simple dashboard to monitor business data without a heavy setup.
